# 📋 Kanban Task Management Board

A responsive and interactive **Kanban Task Management Application** built using **HTML, CSS, and JavaScript**. The application helps users organize, prioritize, and track tasks efficiently through a drag-and-drop workflow interface inspired by modern project management tools.

## 🚀 Live Demo

🔗 Live Demo: [Kanban Task Management Board](https://kanban-board-rp.netlify.app/)

## ✨ Features

* Create, edit, and delete tasks
* Drag and drop tasks across workflow columns
* Organize tasks into **To Do**, **In Progress**, and **Done**
* Assign priority levels (**High, Medium, Low**)
* Set due dates and identify overdue tasks
* Search tasks by title or description
* Track project completion with a progress bar
* Toggle between Dark and Light themes
* Persist task data using Local Storage
* Fully responsive design for desktop and mobile devices

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* DOM Manipulation
* Drag & Drop API
* Local Storage

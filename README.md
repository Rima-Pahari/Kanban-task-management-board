# 📋 Kanban Task Management Board

A responsive and interactive **Kanban Task Management Application** built using **HTML, CSS, and JavaScript**. The application enables users to organize, prioritize, and track tasks efficiently through a drag-and-drop workflow interface.

## 🚀 Features

* Create, edit, and delete tasks
* Drag and drop tasks across workflow columns
* Organize tasks into **To Do**, **In Progress**, and **Done**
* Assign priority levels (High, Medium, Low)
* Set due dates and identify overdue tasks
* Search tasks by title or description
* Monitor project completion with a progress bar
* Toggle between Dark and Light themes
* Persist task data using Local Storage
* Fully responsive design for desktop and mobile devices

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* DOM Manipulation
* Drag & Drop API
* Local Storage
* Responsive Web Design

## 🎯 How It Works

1. Create tasks with title, description, priority, and due date.
2. Manage task progress using drag-and-drop functionality.
3. Track completion status through the progress indicator.
4. Search tasks instantly using the built-in search feature.
5. Switch between Dark and Light themes for better user experience.
6. Automatically save and retrieve tasks using Local Storage.
